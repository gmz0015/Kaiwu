# 变更记录

这里记录对使用者和开发者有影响的变化；功能当前状态以模块 README 为准，技术验证以 docs/VALIDATION.md 为准。

## 维护方式

- 未发布的变更写入 [Unreleased.md](Unreleased.md)，按“新增 / 调整 / 修复 / 移除”组织，只保留实际发生的类别。
- 条目用中文说明行为或开发方式的变化，并标记平台范围，例如 `[macOS]`、`[仓库]`。
- 正式发布时，将对应条目整理为 `<版本号>.md`，注明发布日期、平台范围和升级事项，再从 Unreleased 移除已发布条目。
- 多平台独立发版时使用 `<平台>-<版本号>.md`，避免混淆不同客户端版本；不提前创建空版本文件。
- 配置中的开发版本号不代表已经发布；没有真实发布时不写发布日期或虚构发布链接。
